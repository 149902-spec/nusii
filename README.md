# nusii

A simple static website with Home, About, and Contact pages.

## Files

- `index.html` — home page
- `about.html` — about page
- `contact.html` — contact page
- `style.css` — site styling
- `script.js` — menu, theme toggle, and scroll animation

## Deploy

This project can be uploaded to GitHub Pages directly from the `main` branch.

To publish:

1. Push the repository to GitHub.
2. Enable GitHub Pages in repository settings.
3. Select `main` branch and root as the source.

Alternatively, host on Netlify, Vercel, or Firebase Hosting.
